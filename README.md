# business-knowledge-update

基于本次需求、实际代码变更和相关测试，维护指定的业务知识库，将偏向代码分析记录的内容整理为结构清晰、表达准确、便于开发人员阅读和 Agent 检索复用的中文业务知识。

## 核心功能

- **提取业务规则变化**：结合需求、Git Diff、最终源码及相关测试，识别新增、修改、废弃的规则与受影响的业务能力。
- **复用已有知识**：检索业务术语、别名和规则文档，优先更新已有内容，避免重复沉淀等价业务能力。
- **维护现行规则**：完整描述受影响能力当前有效的业务行为、适用条件、优先级、例外及边界，不堆积需求迭代历史。
- **关联业务与实现**：维护业务 ID、规则 ID、术语引用、代码入口、核心实现和测试位置，支持从业务描述定位已有实现。
- **优化文档质量**：按业务能力、流程和规则主题组织内容，改善中文表达与 Markdown 格式，同时保留既定业务语义。
- **核验一致性**：结合最终代码、测试及已确认的业务要求检查规则准确性、完整性和可追溯性，将冲突、歧义及证据不足的内容单独标记为待确认。

## 处理流程

业务规则提取 → 知识文档生成 → 文档质量优化 → 规则一致性检查。

完成后汇报更新的文档、涉及的业务能力、规则变化、主要结构调整及待确认事项；无需更新时说明原因。

本 Skill 仅手动触发，仅维护本次需求实际影响的知识文档，不修改业务代码。文档质量优化阶段仅调整语言、组织和格式，不改变已记录的业务规则、条件、边界、状态及处理结果。
